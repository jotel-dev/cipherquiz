# Approved CipherQuiz artwork

`cipherquiz-approved.png` is the original **CipherQuiz Geometric Security Logo.png** supplied by the product owner. It is used as an actual image in navigation, footer and gameplay, preserving the geometric purple C, question mark, shield/lock and wordmark. It is not extracted from the landing-page screenshot and has not been redrawn or recolored.

Source SHA-256: `37c508940314e3928f2ee82c7049660f7a2cae9b94b3aa0f7ea88c244bb31058`.

The source is a dark-background raster lockup with white lettering. The site deliberately preserves its original dark treatment. A future transparent/vector or light-background variant should come from the owner, rather than an invented replacement.

The 32px, 64px and 180px PNG favicons are deterministic extracts of the mark from this standalone approved asset, with proportional high-quality downsampling. Reproduce them on Windows with `powershell -ExecutionPolicy Bypass -File apps/web/scripts/prepare-favicon.ps1`. The original full lockup is unchanged.
